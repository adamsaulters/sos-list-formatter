SOS List Formatter

Cleans raw Secretary of State registered-agent exports into the standardized CSV format for the resignation automation --sos-verify flag.

How to use

  1. Select the state you're pulling.
  2. Go to the state's SOS website and search for Registered Agents Inc.
  3. Copy all Active results, paste into the Active box below.
  4. Copy all Inactive results, paste into the Inactive box below.
  5. Click Process, review the counts, then click Download.
